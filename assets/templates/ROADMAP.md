# Roadmap

目标：做出一个**可长期维护、可复现、可审计**的中文版本，而不是一次性补丁。

状态标记：✅ 完成 / 🟡 进行中 / ⬜ 未开始 / ⚠️ 有已知风险

---

## 阶段清单

- ⬜ S0 源准备：镜像号 / 区域 / 可执行文件哈希
- ⬜ S1 容器解包：条目数、类型、对齐、压缩
- ⬜ S2 文本转储：找到"被指令引用"的真源，建立稳定 ID
- ⬜ S3 翻译：分批、术语表、控制码保留
- ⬜ S4 排版：换行独立一遍，行宽上限
- ⬜ S5 字库：格尺寸 / 每页字数 / 运行时上限，三者齐备
- ⬜ S6 图片：先证明编解码幂等，再改像素
- ⬜ S7 重建：条目数一致、容器可自解析
- ⬜ S8 写回：目录/索引/对齐，大小写
- ⬜ S9 回归：模拟器 + 实机，记录覆盖路径
