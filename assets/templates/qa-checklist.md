## L1 结构层

- [ ] 所有译文可编码，0 失败（记录编码与失败数）
- [ ] 控制码数量与原文一致（`hh.py text check` 错误 0）
- [ ] ruby 结构：`#RUBS/#RUBE/#REND` 配对，组数与原文一致
- [ ] 文本表 id 稳定，无重复
- [ ] 字库：字符集全覆盖，未超容量上限
- [ ] 字库：未修改页/字位逐字节相同（回环）
- [ ] 图片：未修改纹理解码→编码逐字节相同
- [ ] 图片：矩形不溢出，别名包全部分发
- [ ] 容器：条目数与源一致，可被自己的解析器完整读出
- [ ] 写回：目录记录 / 索引 / 对齐 / 文件名大小写正确

## L2 语义层

- [ ] 术语表已冻结，术语一致（候选告警逐条处理）
- [ ] 已按源顺序读过的范围：______ / ______
- [ ] 人称、否定、授受、引述四类高危句已专项复查
- [ ] ruby 双层已逐类决定（读音 / 双意 / 强调）
- [ ] 未读范围已明确记录（不是"全部完成"）

## L3 运行时层

- [ ] 模拟器：从新游戏到 ______ 无崩溃
- [ ] 实机：______ 路径通过
- [ ] 菜单 / 战斗 / 存读档 / 设置 抽检
- [ ] 已知问题清单已更新

## 发布说明要求

- [ ] 写明支持的源版本与校验值
- [ ] 写明已完成范围与**未完成范围**
- [ ] 不使用"完美汉化""全部完成""彻底修复"等无证据表述
- [ ] 不含原版资源；只发布补丁或可重建的变更集
- [ ] 已知问题与规避方式
